Installation

Up and running in 60 seconds.

01 — Download
Download the extension ZIP

Click the download button on this page to get the latest .zip archive of the extension.

02 — Extract
Extract the ZIP file

Right-click the downloaded file and choose Extract All (Windows) or double-click (Mac). Note where you save the folder.

03 — Open
Open Chrome Extensions

In Chrome, type chrome://extensions in the address bar and press Enter.

04 — Dev Mode
Enable Developer Mode

Toggle Developer mode on in the top-right corner. The page will refresh with new options.

05 — Load
Load the unpacked extension

Click Load unpacked, navigate to and select the extracted folder. The extension appears in your list immediately.

06 — Done
Visit csgogem.com/rewards

Navigate to csgogem.com/rewards. Your rakeback values appear automatically once the page loads.
